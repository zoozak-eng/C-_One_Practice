Chapter 4: Loops

This chapter explains loops in C#. Loops are used to repeat a block of code multiple times.

Topics Covered

1. While Loop: Repeats statements as long as the condition is true.
2. Increment and Decrement Operators:
   - "++" increases a value by 1.
   - "--" decreases a value by 1.
3. For Loop: Repeats statements using initialization, condition, and update.
4. Do-While Loop: Executes statements at least once before checking the condition.

Examples

- Display Hello five times using a while loop.
- Count numbers using a for loop.
- Increase and decrease variable values.
- Repeat statements using a do-while loop.

Important Notes

- While and for loops are pretest loops.
- Do-while is a posttest loop.
- Infinite loops occur when the condition never becomes false.

Conclusion

This chapter helps students understand how to use loops to repeat statements and control program execution in C#.
