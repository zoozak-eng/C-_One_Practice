1. Sales Bonus Calculation 
This code calculates a sales bonus. If sales are greater than 50,000, the bonus will be 500. Finally, it displays the total sales and bonus in label1.Text.

2. University Age Check (If/Else) 
This code takes a person's age and checks whether it is greater than 18. If the age is greater than 18, it displays a message box saying "Welcome". Otherwise, it displays a message indicating that the person cannot enter the university.

3. Bonus Qualification Check 
This code checks whether a person qualifies for a bonus. First, it checks whether the salary is at least 1000. Then, it checks whether the employee has worked for at least 2 years. If both conditions are met, it displays "You qualify for the bonus". Otherwise, a different message is displayed.

4. Grade Verification 
This code checks a student's marks to determine their grade:
Above 90: A
Above 80: B
Above 70: C
Above 60: D
Below 60: F
Using If And Else If.

5. BMI Calculation 
This code calculates a person's BMI. It also checks whether the weight or height is less than 1 and displays a warning message if necessary. Then, it uses the AND operator (&&) to check whether the person's weight is within the normal range. If the condition is met, it displays "Your weight is normal".

6. Voting Age Verification 
This code checks whether a person is eligible to vote. It checks if the person's age is 18 or above. If the condition is met, it displays "You can vote". Otherwise, it displays "You cannot vote".

7. Sales Goal Check with Boolean 
This code uses a sales value and a Boolean variable called salesQutoMet. It checks whether sales are greater than or equal to 1000. Based on the result, it changes the Boolean flag and displays the appropriate message.

8. String Comparison 
This code compares two strings. Although they may look similar, the computer considers them different because uppercase 'Z' and lowercase 'z' are not the same. If the strings are equal, the message "They are the same" is displayed. Otherwise, the message "They are not the same" is displayed.

9. Age Input Validation
This code uses TryParse to check whether the entered age is a valid number and whether it is less than 0. If both conditions are met, it displays "Invalid number". Otherwise, it displays a message showing the entered age.

10. Empty Name Validation
This code reads the text entered in textBox1 and checks whether it is empty (== ""). If the text is empty, it displays a warning message ("Name is Required"). Otherwise, it displays the entered name in label1.Text.

 **First Class:** Price = 130 //Radio Button
